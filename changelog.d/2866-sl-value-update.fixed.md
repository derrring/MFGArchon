- **The HJB semi-Lagrangian value update reads any separable control cost, not only a quadratic one** (Issue #2866). It was `H(p) - 2H(0)`, which holds only where the control cost is 2-homogeneous in `p`, up to a constant, so a cost that reaches it, such as `L1ControlCost(0.5).regularize(0.1)`, `BoundedControlCost(...).regularize(0.1)` or a smooth non-quadratic `ControlCostBase` subclass, solved a different equation with no error, by an amount that does not refine away: +0.080 on an exact solution where HJB-FDM gives 0. It is now `p*dH/dp - H`, the running cost at the optimal control, reading `dH/dp` from the owner the characteristic foot reads. A quadratic control cost keeps its numbers to round-off, alone or under a `CongestionHamiltonian`; a `CongestionHamiltonian` over another cost moves, since it carried the same error. A `SeparableHamiltonian` whose `is_smooth()` is False, such as one on plain `L1ControlCost` or `BoundedControlCost`, does not reach this update: it takes the DPP search, which this does not change (#2881).
