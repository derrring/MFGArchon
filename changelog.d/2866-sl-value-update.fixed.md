- **HJB semi-Lagrangian reads any separable control cost, not only a quadratic one** (Issue #2866). Its value update was `H(p) - 2H(0)`, which holds only where the control cost is 2-homogeneous in `p`, so `L1ControlCost(0.5).regularize(0.1)`, `BoundedControlCost(...).regularize(0.1)` and any non-quadratic `ControlCostBase` subclass solved a different equation with no error, by an amount that does not refine away: +0.080 on an exact solution where HJB-FDM gives 0. It is now `p*dH/dp - H`, the running cost at the optimal control, reading `dH/dp` from the owner the characteristic foot reads. A quadratic control cost and a `CongestionHamiltonian` keep their numbers to round-off.
- **`diffusion_method='canonical_cs'` refuses a cost it cannot read** (Issues #2866, #1547). **Breaking.** Its objective hand-codes the quadratic `0.5*lambda*|alpha|^2`, so any other cost solved a different equation with no error: -0.248 on plain `L1ControlCost`, -0.169 on `CongestionHamiltonian`, against an exact solution. It now raises `NotImplementedError` when the solver is built, for any control cost other than `QuadraticControlCost` and any Hamiltonian other than a `SeparableHamiltonian`, naming `diffusion_method='adi'`, or `'stochastic'` for a differentiable cost. A hand-written quadratic `HamiltonianBase` read right, and is refused too, since nothing tells it from another. The LQ path with no Hamiltonian is unchanged.
