It holds the layer table and three exception lists: upward edges, owners it cannot place statically, and dynamic import mechanisms by module. It resolves a closed list of binding forms; any other binding makes the name ambiguous, so it may over-report and does not miss. It reports, each at its file and line, an upward import, an unresolved owner or a dynamic import mechanism that is not in its list; and a listed entry the scan no longer finds, a layer prefix that matches no module, and a module no prefix places. It observes: the gate runs only its `--self-test`, which holds the parser, statement-shape, relative-import, layer-table, mechanism and command-line cases.
