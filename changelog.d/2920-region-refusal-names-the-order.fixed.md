- **A `TensorProductGrid` that refuses a region it has not marked says how to place it** (Issue #2920). When a BC segment names a region by `region_name` and the grid has not marked it, the refusal now says to mark the region with `mark_region`, attach the BC with `set_boundary_conditions`, and read it back with `get_boundary_conditions()`. A grid whose axes differ in node layout reads a periodic BC's faces when it is built, before any region can be marked, so build such a grid with a BC that names no unmarked region. Attaching checks the BC against the grid and can refuse it for a reason of its own. The refusal had advised `mixed_bc_from_regions(geometry, ...)`, which needs the region marked first. Refusals on other geometries are unchanged; what their advice says is #2934.
