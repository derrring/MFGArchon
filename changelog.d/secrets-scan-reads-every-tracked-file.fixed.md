- **The custom secrets scan reads every tracked text file.** `.github/scripts/custom_secrets_scan.py` read only files whose suffix it listed. It also skipped every match in a file that held `#`, `//`, `/*`, `"""` or `'''` anywhere. It now reads every file `git ls-files` lists that holds no NUL byte in its first 8000 bytes, as UTF-8 with any byte that does not decode dropped, as it did before. It gains a pattern for a key, token or secret name, then `=` or `:`, then a quoted run of 32 or more alphanumerics; the name's tail after the key word is bounded at 64 characters, and its whitelist reads the value, not the name. Its reports record each finding's file, line and kind, and no longer the matched text.
