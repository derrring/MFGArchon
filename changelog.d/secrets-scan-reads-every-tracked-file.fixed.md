- **The custom secrets scan reads every tracked text file.** `.github/scripts/custom_secrets_scan.py` read only files whose suffix it listed. It also skipped every match in a file that held `#`, `//`, `/*` or `'''` anywhere. It now reads every file `git ls-files` lists that decodes as UTF-8 text, and it gains a pattern for a key, token or secret name assigned a quoted run of 32 or more alphanumerics. Its reports record each finding's file, line and kind, and no longer the matched text.
