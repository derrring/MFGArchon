- **The nD FP velocity calls `optimal_control` on `(N, d)` batches and refuses a wrong-shaped return** (Issue #2330).
  - **Before:** `compute_fp_velocity_field` passed grid-shaped `(nx, ny, d)` arrays, outside the `(d,)` / `(N, d)` contract `HamiltonianBase` documents. Depending on the Hamiltonian and the grid's shape, that raised, returned the right drift, or returned a wrong drift with no error. `CongestionHamiltonian` with a congestion factor that returns one value per node raised a TypeError. A return that broadcast against the grid was spread into every velocity component.
  - **After:** positions, momenta and the own density are flattened to one batch and the result reshaped back. A return that is not `(N, d)` raises, naming the Hamiltonian and the shape.
  - **Refused in nD:** a cross density that is not one value per node, which includes every multi-population stack. It is refused whatever the Hamiltonian does with `m`.
