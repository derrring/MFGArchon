- **`HJBSemiLagrangianSolver` refuses a Neumann value that is not verifiably zero (#1936):** a nonzero constant, a callable (even one returning 0) or a provider, given at construction. It accepted one. With diffusion no path measured converged with it; without diffusion some 1-D paths did, and the refusal gives those results up.
  - **Where g went.** Depending on the path, g reached the gradient's ghost cells, the `FDMApplicator` post-step enforcement, both, or neither: canonical-CS and n-D DPP solved exactly the no-flux problem. The boundary handling of the departure feet and the diffusion step carry no g. An operator-splitting sub-step's post-step enforcement goes through `InterpolationApplicator`, which drops it (#2141); the 1-D stochastic sub-step's goes through `FDMApplicator`.
  - **Measured** on the exact u = A(x − ½)² with its Neumann data g = A, T = 1, at 21 / 41 / 81 points with Nt = n − 1, after #2140 gave the ghost cells the grid's spacing. Error relative to max|u|:
    - **With diffusion (σ = 0.2) no path converged with g.** ADI: 0.041 → 0.118 → 0.192 at A = 0.3, 0.42 → 0.62 → 0.76 at A = −0.3. Stochastic: 0.059 → 0.028 → 0.197 and 0.20 → 0.56 → 0.82. canonical-CS gave its no-flux result. Explicit diffusion's error grew with `no_flux_bc()` as well (0.29 → 0.88 → 2.47 at A = 0.3), so this fixture does not test it.
    - **Without diffusion (σ = 0), at foot CFL 0.3** (no sub-step fired), the 1-D whole step converged with g at first order. `adi`, `explicit`, `stochastic` and `none` compute the same U there (largest difference 1.2e-16 at 41 points), so this is one result, not four. Where characteristics leave the domain (A = −0.3): 0.120 → 0.060 → 0.030, against 0.668 → 0.636 → 0.614 with `no_flux_bc()`. Where they stay inside (A = 0.3) both converge: 0.052 → 0.024 → 0.012 against 0.077 → 0.039 → 0.019. canonical-CS gave its no-flux result in both.
    - **At foot CFL above 1 (σ = 0, A = ±2; up to 2.8, with up to four sub-steps per step)** the result follows the applicator. Where characteristics leave the domain (A = −2), the operator-splitting sub-steps gave nearly the no-flux error (1.88 → 1.90 → 1.92 against 1.87 → 1.90 → 1.92). The stochastic sub-steps, which enforce through `FDMApplicator`, converged: 0.755 → 0.389 → 0.197 against 2.02 → 1.97 → 1.95. A whole step without sub-steps failed (1.48 → 1.80 → 1.88). Where characteristics stay inside (A = 2) every path converged, with g and without.
  - **The refusal gives up the σ = 0 results, and `no_flux_bc()` is no substitute where characteristics leave the domain.** They are the first results an implementation of #1936 must bring back.
  - **How.** It now raises `NotImplementedError` through the same `honors_inhomogeneous_neumann` gate `FPSLSolver` already used (#1686), so a semi-Lagrangian pair was already refused there. `no_flux_bc()` and `neumann_bc(value=0.0)` are unaffected.
  - **The gate's message** names each solver's own reason (`_inhomogeneous_neumann_gap`). For a constant value it now says the value "would not be honoured" rather than "would be silently discarded"; the old phrase was literally true only where the value reached nothing.
