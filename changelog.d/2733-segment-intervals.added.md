- **`ImplicitDomain.segment_intervals(a, b)` and `first_contact(a, b)`: the exact parts of a segment inside an implicit domain, and its first boundary contact** (#2733, PR 1). A `Hyperrectangle` solves a slab test, a `Hypersphere` a quadratic, and the CSG nodes combine their children's intervals, a complement entering as the closed set phi >= 0. Each interval end carries the primitive and face that bound it, and `first_contact` gives the contact's parameter, point and outward normal. Whether a start is inside is decided by the intervals at t = 0, which agree with `contains` there, not by a band around phi = 0. A domain given only by its signed distance is refused by name rather than sphere-traced, since nothing checks that its phi is a distance, and so is a periodic box (#2704). No solver reads this yet; the particle solver's contact loop is #2733's PR 2.
