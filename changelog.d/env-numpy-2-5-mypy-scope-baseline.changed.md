- **The mypy scope baseline is re-recorded for numpy 2.5's type stubs.** The local gate's environment moved to numpy 2.5.3 and mypy 2.4.0, with Python kept at 3.12. Under it `alg` reports 693 type errors instead of 706, and `operators` 35 instead of 34; no other package's count moved. The move follows numpy, not mypy: mypy 2.3 checking against numpy 2.5 gives 693 and 35, and mypy 2.4 against numpy 2.4 gives 706 and 34. A baseline read on another toolchain would report the environment as a change in the tree, and the check's own advice for a change, to re-record, would then overwrite the right baseline. So `scripts/check_mypy_scope.py` now stamps numpy beside python and mypy, and refuses (exit 2, "cannot measure") a check whose python minor version, mypy or numpy differs from the stamp. The refusal names both stamps, which give the versions an interpreter must match, and does not offer to re-record.
