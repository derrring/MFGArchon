- **`QuadraticMFGHamiltonian(coupling_coefficient=c)` refuses c ≤ 0 by name** (#2980), and so does `create_hamiltonian("default", coupling_coefficient=c)`, which builds through it. The constructor built the control cost λ = 1 for any c ≤ 0, so the solve read c = 1 while `coupling_coefficient` still reported c: on #2980's measurement c = 0, −1 and −2 each solved byte-identical to c = 1. c = 0 is no control cost and c < 0 makes ½c|p|² concave in p, so there is no value to fall back to.
