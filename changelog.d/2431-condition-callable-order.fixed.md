- **A time-first `u_terminal` or `m_initial` is read correctly (#2431).** `Conditions(u_terminal=lambda t, x: x**2)` used to give a terminal condition identically $T^2$, with no warning: the IC/BC adapter probed `f(x, t)` before `f(t, x)`, and both return a number. The adapter now asks `bind_user_callable` first, like every other user callable since #2378 phase 5. A callable whose parameter names bind a time slot is read at $T$ for `u_terminal` and $0$ for `m_initial`: `(t, x)`, `(tau, x)`, and a keyword-only `t`. Validation now reads `u_terminal` at $T$ too, so a condition finite at $T$ but not at $0$ (`x**2 / t`) is no longer refused.
