- **A graph node's constant is read by the reader its return is read by, so a NaN or an infinity is refused** (Issue #2861). `NodeBC(value=)`, `set_dirichlet_nodes`, `set_source_nodes`, `apply_direct` and the factories' `boundary_value=` and `source_value=` wrote a non-finite constant into the field, and the solve went on with it, where a grid boundary value refuses one (#2593) and a graph callable's return was already refused. Each now raises `NotImplementedError`. An int too large for a float, which raised Python's unnamed `OverflowError` from a grid constant and from either kind of return, raises a named refusal too. What a graph constant takes is otherwise unchanged: `None`, a masked element and a one-element array stay refused by name, where a grid constant reads them.
