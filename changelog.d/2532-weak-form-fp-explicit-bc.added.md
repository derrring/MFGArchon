- **`FPFEMSolver` and `MeshlessGalerkinFPSolver` take `boundary_conditions=`, the FP's own BC** (#2532). As for every other FP solver that reads a segment BC, a BC handed to the solver is used as given and a NEUMANN in it is refused, while without one the solver reads the problem's shared BC, where a DIRICHLET is an absorbing exit. So a shared `neumann_bc(value=g)` or a shared ROBIN, which the HJB reads, can now run with these solvers too, by giving the FP its own `no_flux_bc(...)`. On FP-FEM an explicit `DIRICHLET(g)` is a prescribed density `m = g`, and an explicit ROBIN is the FP's total-flux Robin, `J.n = (D/beta)(alpha*m - g)`. Meshless Galerkin gains no wall: its explicit NO_FLUX, REFLECTING and absorbing `DIRICHLET(0)` solve as the shared route does, and a DIRICHLET with a value is refused, since no oracle checks a meshless density yet (#2581).
