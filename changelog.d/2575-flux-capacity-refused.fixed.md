- **An FP solver refuses a `BCSegment` that carries `flux_capacity`, which none of them honoured** (Issue #2575). A capped Dirichlet exit was accepted, and the cap ignored, by FP-FDM, the particle solver, FP-FEM and meshless Galerkin, so it solved as uncapped, including through `problem.solve()` with the default scheme. SL, GFDM and FVM refuse a Dirichlet exit outright. On a 21-point 1-D fixture with a cap of 1e-6, FP-FDM's outflow over the horizon was 0.081667 with and without the cap, and the particle solver's was 0.071469 both ways. The particle path that would apply a cap had no caller. `BaseFPSolver._validate_bc_support`, which every FP solver that takes a segment BC reaches on the BC it solves with, now raises `NotImplementedError` for such a segment, on the shared and the explicit route. A network problem carries no segment BC. The HJB side is unchanged and reads a shared exit as u = g. The capacity-limited exit itself is scheduled as a capability in the current phase.
