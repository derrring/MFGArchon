- **1-D `HJBFDMSolver` returns the root it reports for a Dirichlet wall** (Issue #2515).
  - Newton solved the wall node's PDE row and the solver then overwrote `u_wall = g`, so a solve reporting `converged=True` returned an array whose residual was 4.2e+01.
  - The wall row is now `u_wall − g` in both `compute_hjb_residual` and `compute_hjb_jacobian`, so the root satisfies the condition and the wall ghost no longer enters the 1-D solve.
  - The returned solution was already right to first order on an exact Dirichlet solution, which a new test now pins; there it moves by 9.5e-5 / 1.3e-5 / 1.8e-6 at Nx = 41 / 81 / 161. On one backward step whose terminal data disagrees with g at the wall (−0.5 against 0.7, the #1900 fixture), the node next to that wall moves by 0.166 → 0.120 over Nx = 21–321 with no visible common limit: the wall value is now imposed exactly rather than reached at O(h). What changed is that `converged` and the residual now describe the array returned.
