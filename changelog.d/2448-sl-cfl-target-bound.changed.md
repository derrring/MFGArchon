- **`cfl_target` for the semi-Lagrangian pair must lie in (0, 1], and `SLConfig.cfl_number` now sets it (#2448).** `cfl_target` is the crossing a sub-step is *planned* for: the cells its foot would cross at the velocity measured at the step's start. The traced feet run past it (#2439). `HJBSemiLagrangianSolver` took any positive value. On #1880's matrix fixture (σ = 0.2) a seeded asymmetry decays at 0.984 per sweep with the HJB half at 1.0, and grows at 1.005 at 1.02, 1.121 at 1.1 and 2.190 at 1.5: the margin at 1 is thin. Both constructors, and `cfl_substeps`, now refuse a value outside (0, 1]. `FPSLSolver`'s `cfl_target` (new with #1880) shares the range, because the pair factory hands the HJB half's value to it; an FP half alone was stable to 1.5.
  - `SLConfig.cfl_number` raised `NotImplementedError` for any value but its default, and an explicitly set default (0.5) was silently ignored while the solver ran at 0.9. It now defaults to None, meaning the solver's own. A set value reaches the HJB half as `cfl_target`, and the pair factory hands it to the FP half. A config that set 0.5 now runs at 0.5.
