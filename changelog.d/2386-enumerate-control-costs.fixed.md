- **The evenness that #2375 ruling 5's "nothing in this library changes value" rests on is now checked for every control-cost class defined at module level in the package** (#2386).
  - `test_conjugate_is_alpha_sign_blind` promised in its docstring that *"if a non-even control cost is ever added, this test fails"*. It could not: it iterated a three-entry hand-written dict, which was already missing `_MoreauYosidaControlCost`. Measured with a deliberately non-even cost added to the library: 38 passed, 0 failed.
  - It is now parametrised over the imported `ControlCostBase` subclasses, and asserts `L(a) == L(-a)` bit-exactly before comparing the two conjugates. The conjugate comparison alone runs through `minimize_scalar` at `abs=1e-6`, and an odd term `eps·a` on a quadratic cost moves it by `2·p·eps/λ`, so it cannot see `eps` below about `λ·6e-8`.
  - `__subclasses__()` only sees classes some module has already imported, and a parametrisation is fixed at collection. So a new test, `test_every_library_control_cost_is_even`, imports every module in a **child interpreter**, enumerates the concrete library costs there, builds one instance of each (defaults, with required arguments filled from a fixed table), and asserts `L(a) == L(-a)` bit-exactly at values of α inside the admissible set and that `effective_domain()` is symmetric; the two conjugates agree when both hold. It fails if the child read a different tree, if any `.py` file under the package was not reached (`pkgutil.walk_packages` does not enter a directory without `__init__.py`), if any module fails to import, or if a class it enumerated was not probed. Not checked: an instance built with other arguments (a class even only at its defaults passes), α with more than one component, and a class defined inside a function. The sweep runs out of process on purpose: run in the test process, it pre-imported the renamed shim modules for later tests on the same worker, and the warning census could then lose their `DeprecationWarning`s, depending on xdist scheduling.
  - Measured both ways: a non-even cost, or an even one with a one-sided admissible set, in a module collection never imports fails the new test and names the class, as does a module in a directory without `__init__.py`; an even symmetric one passes, including one whose `lagrangian()` is undefined outside its admissible set; removing the child's import loop makes the non-even case pass again.
  - A red here does not mean "make the cost even". Ruling 5 exists so the library is correct for a non-even cost; it means that class's hand-written closed forms for `H` (`evaluate`, `optimal_control`, `dp`) must be derived under `H = sup{-p·α - L}`, and the "nothing changes value" paragraph no longer holds.
  - The test docstrings that still stated the pre-#2375 pairing `sup{p·α - L}` now state `sup{-p·α - L}` (#2387).
