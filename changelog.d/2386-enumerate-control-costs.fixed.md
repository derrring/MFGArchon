- **The non-even-control-cost tripwire now enumerates subclasses instead of a hand-written list** (#2386).
  - `test_conjugate_is_alpha_sign_blind` promised, in its own docstring, that *"if a non-even control cost is ever added, this test fails"*. It could not: its population was a three-entry dict, so a fourth cost was covered only if whoever added it remembered — and the dict was **already missing `_MoreauYosidaControlCost`**, which has been a `ControlCostBase` subclass all along. The pin is now parametrised over `ControlCostBase.__subclasses__()` and covers four classes rather than three.
  - **Why it mattered enough to fix on its own.** #2375 ruling 5's user-facing guarantee — "nothing in this library changes value" — holds exactly while every shipped control cost is even in α, because `sup{-p·α - L}` equals `sup{+p·α - L}` only then. That evenness was true and measured by hand; no test asserted it. A guarantee CI does not check is one release away from being false.
  - **Measured, both directions.** Adding a deliberately non-even cost to the library: the old dict-based tests give **38 passed, 0 failed** — completely blind. The enumeration gives **2 failed**, naming the class in the parametrised ID and again in the completeness gate. The library was restored and its sha256 re-verified after each run. The evenness is asserted **bit-exactly** on `lagrangian` rather than through the conjugate, which runs via `minimize_scalar` at `abs=1e-6`: measured, that tolerance is silent at an odd term of `1e-7` while `|L(a) - L(-a)|` is already `1.6e-6`. The direct check catches `1e-9`.
  - **The blind spot is removed, not detected.** `__subclasses__()` sees only classes some module has imported, so a cost in an unimported module is invisible while the result looks complete. A first version read the population a *second* way, by AST, and review measured that instrument against four ways of writing such a cost: it caught **one**. An aliased import (`from x import ControlCostBase as CCB`) defeats a name match in any file, and accumulating known bases in one `rglob` pass misses a subclass of a *concrete* cost in a file walked before `hamiltonian.py` — the same snippet caught under `backends/` and blind under `core/`, decided by directory order. Fixing that resolver was the wrong move; star imports, dynamic base tuples and `__init_subclass__` are three more holes it would still have. Instead every module in the package is imported first (372 here, 0 failures, 4.2 s), after which the runtime enumeration has nothing left to be blind to. All four shapes are now caught. The import sweep's own warnings are suppressed: it is instrumentation, not subject, and an `ImportWarning` naming absent optional dependencies would otherwise make the committed warning census machine-dependent.
  - **`CONTROL_COSTS` stays hand-written on purpose** and gains a gate instead. Each entry is paired with a conjugate transcribed by hand in `CONGESTION_L_CTRL`, and that independence is what gives the congestion round trip teeth, so the dict cannot be derived. The gate fails and *names* an uncovered subclass, so a new cost cannot arrive without its conjugate. The evenness pin needs no transcription and covers a new class immediately.
  - **A cost whose required constructor argument is unknown raises rather than being skipped**, and the factory's output is pinned to its input. A silently skipped subclass is indistinguishable from a covered one — and so is a silently MIS-constructed one: measured, making `_construct` always return `QuadraticControlCost` left the file green with three of four parametrised ids advertising a class they did not exercise. The `_MoreauYosidaControlCost` specimen wraps `L1ControlCost`, not `QuadraticControlCost`: `regularize()` returns `self` for a smooth cost, so a Quadratic-based one is a specimen the library cannot produce, and its `effective_domain()` is `None` — probing neither the `ℓ1` kink nor a saturated boundary.
  - **What a red here means.** Not "make the new cost even" — ruling 5 exists so the library is correct for a non-even one. It means the four analytic closed forms on `ControlCostBase` subclasses must be re-derived: `evaluate`, `optimal_control` and `dp` are hand-written and correct only while `L(-a) == L(a)`. The failure message says so.
