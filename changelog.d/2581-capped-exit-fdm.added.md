- **A capacity-limited exit on FP-FDM** (Issue #2581, PR 2a). `flux_capacity = c` on a `DIRICHLET` exit with value 0 of `FPFDMSolver`'s own `boundary_conditions` caps the exit's outflow at `c` per unit boundary measure: on the exit, m >= 0, J.n <= c and m (c - J.n) = 0, so the excess queues in the domain. Each implicit step starts every exit node absorbing, caps the nodes whose outflow over the step would exceed `c |face| dt` with the FLUX(c) row, and solves again. For a standalone FP solve only: a coupled solve refuses it, since paired with an HJB reading `u = g` at the exit it is not an equilibrium. A cap on the shared BC, on `divergence_centered`, on a `DIRICHLET(g != 0)`, on a face that meets a face not governed by NO_FLUX, and on every other FP solver is refused by name.
