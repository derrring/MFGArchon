- **A test is slow when it carries `@pytest.mark.slow`, no longer when its name contains "large", "slow" or "benchmark"** (Issue #1875). The gate deselects `slow`, so the name rule in `tests/conftest.py` kept descriptive, fast tests out of it with nothing at the test to show it. At `bfdab257` it held 31 cases out; together they run in 0.40 s. Among them was #1684's pin that `MultiPopulationResult.errors` takes the max over fields, and #2570's max-over-fields pins were held out the same way until #2570 renamed them. The gate collects 4730 tests where it collected 4695: those 31, and this change's own four.
  - A test whose function name says "slow" or "benchmark" must carry the matching marker; collection refuses the session otherwise.
  - `scripts/oracle_pins.txt` lists the tests #2512's progress counts: 18 oracle cells, convention C1, and five pins. A new gate step, `scripts/check_oracle_pins.py`, collects each under the gate's markers and fails if any is deselected or missing, so a counted pin cannot leave the gate silently.
