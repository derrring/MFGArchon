The gate deselects `slow`, so the name rule in `tests/conftest.py` kept descriptive, fast tests out of it with nothing at the test to show it. The gate collects 4734 tests where it collected 4695: those 31, and this change's own eight.
  - A test whose function name has "slow" as an underscore-separated word must carry `@pytest.mark.slow`. It fails at setup otherwise, with a message that says to rename it or declare it.
