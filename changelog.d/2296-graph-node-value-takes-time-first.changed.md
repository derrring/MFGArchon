- **A graph node's value takes `(t, node)`, time first, and a CUSTOM node takes a rule of `(t, node, field)` as `rule=`** (#2296, #2512 row N2). **This breaks a callable written in the old order.**
  - **How the library calls them.** `NodeBC`, `set_dirichlet_nodes`, `set_source_nodes`, `apply_direct` and the factories bind a callable value once to `(t, node)`; `set_custom_bc` and `NodeBC(rule=)` bind a rule to `(t, node, field)`.   - **Refused by name where it is built:**
    - a value written `(node, t)`, the order `NodeBC.get_value` called it in. The refusal names `(t, node)`;
    - a callable whose parameters are not all named after the slots, such as `lambda a, b: …` or `lambda t, n: …`. At main a two-parameter callable was called `(node, t)` whatever its names, so `lambda n, s: 100*s + n` read correctly, 51.0 at node 1 and t = 0.5; write it `lambda t, node: 100*t + node`;
    - a callable that is not a function you write (a class instance, a builtin, a ufunc, a def that a decorator turned into another object such as `functools.cache`, `lru_cache` or `numba.njit`, a jax-wrapped function), or whose signature cannot be read, or that has positional-only parameters.   - **Refused by name where it is read:** `get_value` and `get_bc_value` on a CUSTOM condition, which has a rule and no value. At main they read a CUSTOM condition's value as any other's: a scalar was returned (3.0 for `value=3.0`), and a `(field, node, t)` rule raised `TypeError: … missing 1 required positional argument: 't'`, naming nothing.
  - **What a value or rule returns is read as a grid boundary value's return is**, by its one reader, `types._read_constant` (#2512 row B2). It refuses `None`, a bool, a complex number, a non-finite number, more than one number, and any other value that is not a real number (a string other than one it reads as zero, a `Decimal`, an object array); it reads a masked element, and what it calls zero (`'0'` and `b'0'` among them), as 0, and an array of one element as that element.   - `set_custom_bc`'s `bc_func` is the rule. At main it was documented and called as `(field, node, t)`; that order is refused now.
