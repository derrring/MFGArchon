- **The stochastic semi-Lagrangian HJB path evaluates a sub-step's foot velocity and value update at the step's time (#2450).** When it sub-stepped, it evaluated `dH/dp`, the value update and (in 1-D) its post-step boundary enforcement at `time_idx` times the *sub-step's* `dt`: neither the step's time nor the sub-step's. It now uses the step's time `time_idx * dt` for the foot velocity and the value update in every dimension, as the pointwise path and the sub-step schedule do, and for the post-step boundary enforcement in 1-D. For a time-independent Hamiltonian with time-independent boundary data nothing changes (U byte-identical, 1-D and 2-D). Under `H = (1 + 4t)|p|^2/2 - m`, the stochastic solve's distance from a CFL-refined ADI solve falls from 2.6e-2 to 2.6e-3 (σ = 0.2), and from 3.6e-2 to 6.0e-3 at σ = 0.05. Other reads of time-dependent boundary data remain at t = 0 on some paths; #2453 lists them. The same expression in the canonical-CS step is corrected too; that path does not sub-step, so its output does not change.
