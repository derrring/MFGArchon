- **The model form declares a network MFG** (#1472, stage 2a). `MFGProblem(model=Model(hamiltonian=NetworkHamiltonian(...)), domain=<network geometry>, conditions=Conditions(...))` builds a problem the network solvers solve: the problem binds the `NetworkHamiltonian` to its geometry. Each network solver refused such a problem by name before.
  - **A problem on a network refuses, when it is built and by name, a Hamiltonian that is not a `NetworkHamiltonian`.** One such as a `SeparableHamiltonian` built, and every network solver refused it.
  - **A `Conditions` callable on a network is read once at each node, with the node as `x`, an `int`** (the user's ruling of 2026-11-28; `docs/user/CONVENTIONS.md` § *Callable signatures*). It was handed the geometry's node coordinates as a coordinate tuple, a batch of every node and one sample point, so a callable that indexes by the node, such as `lambda x: weights[x]`, is read as written now.
  - **`NetworkMFGProblem` builds the model form**, its node fields as its conditions. `get_m_initial` and `get_u_terminal` return what `initial_node_density_func` and `terminal_node_value_func` give: they returned the uniform density and zeros whatever was given. An initial density whose node sum is not 1 is reported and warned about, as on every geometry; it was not.
  - **A network solver reads the node BCs from the geometry when it applies them.** A node BC the geometry is given after the solver was built is applied by `FPNetworkSolver` and `NetworkPolicyIterationHJBSolver`, and refused at the solve by `NetworkHJBSolver`, which applies none. All three ignored it.
  - **`Model(coupling_cost=...)` and `Model(terminal_coupling=...)` on a network** are still refused; the refusal names `NetworkHamiltonian(node_potential_func=...)` and `Conditions(u_terminal=...)` instead.
- **An FP solve handed no initial density starts from the problem's** (#1472). `BaseFPSolver.solve()`, and `FPFVMSolver.solve_fp_system` handed none, read `get_m_initial`. They read `get_initial_density`, which only `NetworkMFGProblem` defines, so on any other problem they raised `AttributeError`.
