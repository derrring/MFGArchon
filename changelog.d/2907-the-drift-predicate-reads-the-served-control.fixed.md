- **`-c*grad(U)` drives the FP only for a Hamiltonian and its cost exactly as the library ships them** (Issues #2907, #2914). `drift_is_the_control_costs` compared a `QuadraticControlCost`'s type attribute with the library's, so a cost serving another control on its instance, through `__getattribute__`, a descriptor, a partial, a callable object or another cost's library method, was taken for the library's. `problem.solve()`'s default scheme and FP-SL then drove the FP by `-c*grad(U)` with no error: 1.2074e+00 and 1.4437e+00 off in M from the library Hamiltonian for the same H (1-D no-flux, 21 nodes, at 8f7c0db8).
  - **Now the rule checks types** (user ruling, 2026-11-09). The Hamiltonian must be a `SeparableHamiltonian` or `QuadraticMFGHamiltonian` exactly, its cost a `QuadraticControlCost` exactly, and neither instance may hold a family method. It is read by the one owner of "as the library ships it" (`_why_not_as_it_ships`, which #2899's rows path reads too). A subclass, a forwarding wrapper or an instance entry is not certified, whatever it serves or reports, and its control is read as served. A cost whose `lambda_` disagrees with the `_lambda` its body reads is no longer taken at `lambda_`.
  - **Where such a Hamiltonian goes.** The default scheme takes its control as a velocity on #2900's set, widened by #2908, and solves as the library Hamiltonian it describes. A consumer that takes the value function only refuses it, naming why it is not as shipped: FP-SL, FP-FDM handed `potential_field=U` directly, the two advection builders, and the meshless HJB's streamline diffusion. So does the default scheme outside the set: `FDM_CENTERED` and `RegimeSwitchingIterator`.
  - **Changed for a plain subclass of a shipped class.** Each of those consumers solved it before, since it serves the library's control, and now refuses it. On the default scheme inside the set it still solves as the library Hamiltonian it is, through the velocity route.
  - **Patching a library class at run time is unsupported:** such a class reads as shipped (#2917).
