- **Docstring examples get two guards, and both state how much of the package they cover** (Issue #2346).
  - **The problem, measured at `408415d4`:** the package carries 2439 docstring examples over 182 modules and **nothing executed any of them**. #674 removed a positional constructor and left 36 of 37 examples dead, 7 raising `TypeError`; #2341 repeated it at one line, where `MFGProblem`'s Hamiltonian example taught `QuadraticControlCost(1.0)` that #2345 then made raise.
  - **`--doctest-modules` is not available to this package, and the measurement is why.** Executing all 2439 gives **1348 failures**, of which **1153 are `NameError`** — examples written as narrative fragments using names from a neighbouring docstring. `doctest` isolates per docstring, so those cannot pass under any runner; turning execution on package-wide is a documentation rewrite, not a check.
  - **Executable allowlist** (`tests/unit/test_docstring_examples_2346.py`): the 24 modules whose examples already all pass — 178 examples — now run in the suite. The file states that it covers 24 of 182 and has a test asserting the ratio, so it cannot be read as "the package's examples are checked". Growing the list is deliberate.
  - **Static keyword check** (`scripts/check_docstring_kwargs.py`): every keyword argument in a docstring example must be a real parameter of the callee it names. It needs no executability, so it sees all **643** docstring blocks, and it fires on exactly the event the deprecation-removal batches (#2343) generate. Baseline: **22 findings of 1029 keyword arguments checked**, e.g. `TensorProductGrid(periodic_dims=...)`, which documents a parameter the signature does not have.
  - The checker resolves a callee in the example's own module namespace before falling back to a bare-name map; the bare-name map alone resolved `MFGComponents` to the wrong class and manufactured 7 findings that do not exist.
  - **Exposure this protects, for the batches behind it:** #2343's nine batch-1 symbols appear in 2 example blocks and `CongestionHamiltonian` (#2331) in 1, so those do not depend on this. The rename families do: `Nx` → `Nx_points` is in **40** blocks across 12 files and `drift_field` → `potential_field` in **23** across 4. `Nx` is still an accepted alias today, so those blocks are correct now and break when that family is removed.
  - The gate's own comment that "docs are the one artefact nothing else runs" is corrected rather than left standing, since 178 examples now run.
