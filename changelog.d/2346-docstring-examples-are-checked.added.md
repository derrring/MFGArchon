- **Docstring examples get two guards, and both state how much of the package they cover** (Issue #2346).
  - **The problem, measured at `408415d4`:** the package carries 2439 docstring examples over 182 modules and almost nothing executed any of them — `tests/unit/test_geometry/test_tensor_grid_docstring_examples.py` (#1638) covers one class, and nothing else ran. #674 removed a positional constructor and left 36 of 37 examples dead, 7 raising `TypeError`; #2341 repeated it at one line, where `MFGProblem`'s Hamiltonian example taught `QuadraticControlCost(1.0)` that #2345 then made raise.
  - **`--doctest-modules` is not available to this package, and the measurement is why.** Executing all 2439 gives **1348 failures**, of which **1153 are `NameError`** — examples written as narrative fragments using names from a neighbouring docstring. stock per-docstring isolation cannot supply those names, and a collector sharing globals across a module recovers only 154 of the 1153; turning execution on package-wide is a documentation rewrite, not a check.
  - **Executable allowlist** (`tests/unit/test_docstring_examples_2346.py`): the 24 modules whose examples already all pass — 178 examples — now run in the suite. The file states that it covers 24 of 182 and has a test asserting the ratio, so it cannot be read as "the package's examples are checked". Growing the list is deliberate.
  - **Static keyword check** (`scripts/check_docstring_kwargs.py`): every keyword argument in a docstring example must be a real parameter of the callee it names. It needs no executability, so it reaches **624** of the 643 docstring blocks — the other 19 do not parse as Python and are excluded from the count rather than counted as analysed, and it fires on exactly the event the deprecation-removal batches (#2343) generate. Baseline: **21 findings of 1027 keyword arguments checked**, e.g. `TensorProductGrid(periodic_dims=...)`, which documents a parameter the signature does not have. The baseline also records the population (`checked`, `blocks`) with a 10% floor, so a scanner that goes blind — an optional dependency making modules unimportable — fails instead of reading as an improvement.
  - The checker resolves a callee in the example's own module namespace before falling back to a bare-name map; the bare-name map alone resolved `MFGComponents` to the wrong class and manufactured 7 findings that do not exist.
  - **Exposure this protects, for the batches behind it** — counted in doctest blocks, the same unit as the 643/624 above, because an earlier version of this table mixed block counts with `>>>`-run counts: #2343's nine batch-1 symbols appear in **2** blocks, one of which is `deprecated_alias`'s own docstring demonstrating itself and defines the symbol locally, so real exposure is **1**; `CongestionHamiltonian` (#2331) is **1**. The rename families are where it lives: `Nx=` in **38** blocks, `drift_field` in **7**. `Nx` is still an accepted alias today, so those blocks are correct now and break when that family is removed.
  - The gate's own comment that "docs are the one artefact nothing else runs" is corrected rather than left standing, since 178 examples now run.
  - **Found by the review of #2351 and not fixed here:** `tests/unit/test_alg/test_fp_particle_solver.py::TestFPParticleSolverCallableDrift::test_callable_drift_with_array_diffusion` is an unseeded 1000-particle Monte-Carlo that passes 8/8 in isolation and can fail under xdist, because its RNG state depends on what ran before it in the same worker. Adding 25 tests changes that distribution. The defect is pre-existing and this change makes it reachable; filed as #2352 rather than seeded here, since seeding another module's test is a different change.
