- **Recorded, not fixed: `NetworkMFGProblem` reports `1/N` as its initial mass** (Issue #2177, surfaced by #1887). `_measure_initial_density`'s ladder falls through to `point-average` — `sum(m) / num_spatial_points` — for a network geometry, so a 5x5 `GridNetwork` whose density sums to exactly 1.0 reports `initial_mass = 0.04` and warns that it is not 1, with a remedy (divide by the integral) that is inert. The `node-sum` branch written for this case never executes: `topology.py:429` sets `self.dimension = "network"` *after* `super().__init__()`, and the measurement happens inside that call, so the guard reads `dimension == 2`. Pre-existing (#2145); what #1887 changes is that the wrong number is now *published* and *warned about* rather than consumed silently. #1887 also improves this path — the old constructor divided by `1/N`, i.e. multiplied every node by N — and stopping that is right.
