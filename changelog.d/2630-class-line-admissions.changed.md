- **AGENTS.md § *Local patches are the anti-pattern*: the class line and its admissions say what is checked, and
  where** (#2630, from review 3 of #2622).
  - The population counts members that are still defective. A site kept with a pin showing it matches the owner is
    not one, so a lexical predicate cannot turn a class fix into an unadmitted partial fix.
  - The control is found at both shas and sits outside the count, so a head count of 0 is not a null result with no
    control.
  - The remaining members are listed in an open issue the PR does not close. A merged PR body tracks nothing, and
    neither does a closed issue.
  - **A staged fix** names its stages in an issue comment that records the plan's approval by someone other than its
    author and that the class line links. "An approved plan" named no place and no record of approval.
  - **A fix that waits** waits on a ruling that is not the author's to make, or on code outside this repository, with
    the issue that records it as open. "A decision" admitted the author's own open choice.
  - § *Review before merge*: a missing **or incomplete** class line is a Must-fix.
