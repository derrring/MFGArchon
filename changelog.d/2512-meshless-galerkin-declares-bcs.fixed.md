- **The meshless Galerkin solvers declare the BCs they honour, so the gate refuses the rest** (#2512 S4).
  - `MeshlessGalerkinHJBSolver` and `MeshlessGalerkinFPSolver` declared nothing, so `_validate_bc_support` returned early and every BC constructed.
  - Measured at `7eb53144`: the HJB solved `neumann_bc(value=0.7)` identically to 0.0, the FP solved `neumann_bc(value=1.0)` identically to no-flux, and PERIODIC and ROBIN raised only once the solve reached a condensation hook.
  - Now both declare {NO_FLUX, NEUMANN, REFLECTING, DIRICHLET}, and a nonzero Neumann value is refused on both. Neither assembles a boundary load.
  - **A DIRICHLET `default_bc` that governs some face is refused.** Nitsche reads only segments, so before this a default-DIRICHLET right wall kept all its mass (ratio 1.0000), where the same wall written as a segment absorbs (0.8326; 11 points, δ = 0.35, σ = 0.3, T = 0.5, m0 = 1, zero drift). A uniform `dirichlet_bc()`, whose one unrestricted segment covers every face, is unaffected. Coverage is the BC object's own face reader (`_segment_covers`), so face aliases and region-named segments are read correctly.
  - **The guard's limits are that reader's.** A segment restricted by `region`, `sdf_region` or `normal_direction` counts as covering every face it names or, with no `boundary`, every face. A DIRICHLET default that governs a face outside that region is still solved there as the natural condition, as on main (#2490). A `boundary="all"` segment covers no face in that reader, so NO_FLUX `boundary="all"` with a DIRICHLET default is refused, although main solved it (#1953).
  - **A shared Dirichlet value is an exit** (#2512, convention row 5). The HJB imposes u = g by Nitsche, and the FP reads the BC through `fp_view_of_shared_bc`, where it is an absorbing wall. An exit cost runs through `create_paired_solvers(MESHLESS_GALERKIN)`: u = g at both walls, mass falling. It did on main too, with identical numbers, and is now pinned. The FP builds its Nitsche terms without the value, so the translator changes nothing it computes; it is there so this FP reads a shared BC through the one owner of convention row 5.
  - **Behaviour change:** PERIODIC, ROBIN, a nonzero Neumann value, and a DIRICHLET `default_bc` left to govern a face now raise at construction.
