- **The node a network solver hands a Hamiltonian as `x` is an `int`** (#3012). `GraphGeometry.node_x(i)`, new, builds it, and every network solver hands it. `FPNetworkSolver`'s rates and `NetworkPolicyIterationHJBSolver`'s handed `np.array([i])`, so a `NetworkHamiltonian` subclass that indexes `x` there sees an `int` now.
  - **A `NetworkHamiltonian` method you call yourself** reads `x` as before when it is an `int` or an array holding one integer. It now refuses by name an array of more than one entry, where it read only the first, and a value that is not an integer, which it truncated.
