- **A raw Hamiltonian callable must declare `p`, and need declare no more** (user ruling, 2026-11-03). `HAMILTONIAN_SLOTS` required all of `(t, x, p, m)`, though a Hamiltonian with no `m` is legitimate: `SeparableHamiltonian(control_cost=...)` with no coupling solves, and every other table takes a callable with no `m`. `(t, x, p)`, `(x, p)`, `(p)` and `(t, p, m)` are now accepted by name and read right, through `validate_hamiltonian` too. One that does not read `p` stays refused, and so does one that names only `p` and reads the other three by position.
