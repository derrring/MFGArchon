# The tests that #2512's progress counts, so that a pin which leaves the gate turns the gate red
# instead of quietly lowering the real count (#1875). `scripts/check_oracle_pins.py` collects every
# target below under the gate's marker expression, `scripts/ci_markers.txt`, and fails if any is
# deselected or missing. A cell counts only when all of its lines collect.
#
# One line per target: <kind> <label> <target>. A target is a pytest node ID, or a test file, which
# then requires every test in that file to collect. Kinds:
#   oracle      an oracle cell of #2512 (a), labelled <family>/<cell>
#   convention  a convention of #2512 met in code, labelled by its id in docs/user/CONVENTIONS.md
#   pin         a pin a batch rests on that is not a cell itself
# A batch appends its own lines in the PR that counts its cells.
