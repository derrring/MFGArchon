# The tests that #2512's progress counts, so that a pin which leaves the gate, or stops passing in it,
# turns the gate red instead of quietly lowering the real count (#1875). `scripts/local_ci.sh` writes the
# suite's own results as JUnit and `scripts/check_oracle_pins.py` reads them: a target counts only if it
# passed in that run.
#
# One line per target: <kind> <label> <target>. A target is a pytest node ID, or a test file, which then
# requires every test pytest collects from that file to pass. A target of `-` declares a part nothing
# pins yet: it counts in the denominator and keeps its label unmet. A label is met only when it has at
# least one target, no `-` part, and every one of its targets passed. Kinds:
#   oracle      an oracle cell of #2512 (a), labelled <family>/<cell>; 38 cells, BC type x dimension
#   row         a (b) row of #2512 (comment 6054006841), labelled <grid|network>/<row>
#   convention  a convention ruled 2026-10-08, labelled C1-C6 as #2429 numbers them
#   pin         a pin a batch rests on that is not a cell itself
# A row is met only by a structural guard that fails if a rival reader reappears, with a planted-rival
# control in the same check; an owner existing, or a behavioural test of it, does not meet it. A
# convention whose ruling names an owner needs both: behavioural pins over every current consumer, and
# such a guard over the owner. Ruled by the audit session, 2026-10-09: #2512 comment 6073690080.
# A routing pin proves only that a cell solves as another one, so a cell pinned that way also carries a `-`
# part, under a comment naming the cell it awaits, until that cell is met; the PR that meets it replaces the
# `-`. An FP NEUMANN cell awaits the NO_FLUX cell of its family and dimension. Ruled by the audit session,
# 2026-10-09: #2512 comment 6079979873, superseding the counting subsection of comment 6054006841.
# A batch replaces its own `-` lines with targets in the PR that counts its cells.
